# igs-iec-tase2

A TASE.2 (IEC 60870-6) client on `igs-iso9506-mms`: the association, the data values, the data sets, the transfer sets and their reports, the devices, and the information messages.

Part of the `igs-iec-tase2` workspace, which depends on `igs-iso9506-mms` 1.1.0. The repository's
[README](https://github.com/aklira/igs-iec-tase2) describes the architecture and the limits of what is served, and the
[CHANGELOG](https://github.com/aklira/igs-iec-tase2/blob/main/CHANGELOG.md) lists each release.
