# M2 — Indication points

## Prompt

Run task M2 of `IMPLEMENTATION.md`: the state, real and discrete values of the indication points, with their quality
flags, in every variant. Read IEC 60870-6-802 §5.2, §6.2 and §7.1. Done when each variant round-trips and each flag is named
and tested.

## Summary

- **Flags**: `crates/igs-iec-tase2-model/src/indication.rs`: the enumerations `Validity`, `CurrentSource`, `NormalValue`,
  `TimeStampQuality` and the two-bit code `TwoBitCode`; the accessors on `DataFlags` and `DataState` (validity, current
  source, normal value, time stamp quality, the state), and on `DataStateSupplemental` (state, tag, expected state). The
  accessors write only their own bits (the unused bit 0 of `Data_Flags` is kept).
- **Variants**: the generator now converts every structure, bit string, enumeration, octet string and array to MMS (D-015).
  The sixteen indication variants of 802 §6.2.1 round trip through their components.
- **Generator**: the bit accessors of the generated types are named `is_<flag>` (for instance `is_normal_value`), so that
  the semantic accessors of the flags keep their names.
- **Decisions**: D-015 to D-018.
- **Tests**: `tests/indication.rs` (15 tests): each flag at its bit, the 64 combinations, the states, the supplemental
  value, the sixteen variants, the refusals of a malformed structure and of a malformed bit string. `tests/generated.rs`
  keeps its counts.
- **Gate**: recorded with the commit.

## Found on the way

- The first test of the state codes assumed that code 01 is bit 0: the data give `State_hi` as bit 0, so code 01 (the low
  bit) is bit 1. The expectation was corrected, not the code.
- The generated bit accessor `normal_value` (a `bool`) collided with the semantic accessor of the same name; the generated
  bit accessors are now `is_<flag>`.
- The standard does not name the state codes (§8.2 gives a table per device): the model keeps the codes, D-017.

## Reading

IEC 60870-6-802 §5.2.2 (the IndicationPoint object and its attributes), §6.2.1 (the flag strings and the variants), §7.1.1
(the mapping onto MMS, with the bit positions), §8.2 (the state codes of each device). No standard text is in the code or
the documents.
