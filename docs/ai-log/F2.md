# F2 — Code generation

## Prompt

Run task F2 of `IMPLEMENTATION.md`: `cargo xtask codegen` reads both `mms_types.yaml` files and writes
`crates/igs-iec-tase2-model/src/generated/`, with a "generated, do not edit" banner citing clauses. A name defined in
several clauses is scoped by clause. Generated files are committed; `--check` fails when they are stale. Done when
the code compiles and a test asserts 111 + 40 names and the component and bit counts.

## Summary

- **Generator**: `xtask/src/codegen.rs`. It reads the two data files (123 definitions in 802, 49 in 503), resolves every
  reference, and writes `iso802.rs`, `iso503.rs` and `mod.rs`, formatted by `rustfmt`.
- **Generated types**: one Rust type per definition: a newtype with its range (integers), its maximum length (strings,
  octets), its flags (bit strings, with a mask and an accessor per flag), its components (structures), its enumeration
  values, or an alias (references). Inline component types are named after their parent and field.
- **Scoping**: the 9 names of 802 and the 6 of 503 defined several times live in modules named after their clauses
  (D-001). References resolve as recorded in D-006.
- **Metadata**: `DEFINITIONS` (every definition: name, standard, clause, page, kind, components, bits) and `VARIABLES`
  (the 19 variables of the bilateral table of 503).
- **Support types**: `value.rs` (the metadata, the range and length errors), `builtin.rs` (the base types, by hand).
- **Decisions**: D-001 (tested), D-002 (tested), D-003 (used by D-006), D-004 to D-008.
- **Tests**: `crates/igs-iec-tase2-model/tests/generated.rs` (six tests: the counts, the components, the bits, the
  variables, the scoping of `Number`, the flags of `DSConditions`, the spelling, the plain integer), and `builtin.rs`
  (four tests of the limits).
- **Check**: `cargo xtask codegen --check` passes on the committed files. It was tested on a stale file: it fails, and
  names the file.

## Found on the way

- Two references of 802 point to definitions of 503 (`GMTBasedS`, `TimeIntervalS`, `TAConditions`): the two files
  share their types, so the references resolve across them.
- The extraction names the plain `INTEGER` of `NumPeriods` as a reference to `integer`: resolved as a 32-bit integer (D-005).
- The first attempt mapped `InfoMessHeader` to a path that does not exist: the definition is in 802 itself. The entry
  was removed, and the name resolves through the common namespace.
- A bare `cat >` in a shell waited for input and blocked a command: it was stopped, and the counts were read again.

## Not decided here

- Widths of visible strings: maxima (D-004), to be confirmed at M1.
- The conversions to and from MMS `Data`, and the range checks of the arrays: M1.

## Reading

IEC 60870-6-802 §6 (types), annex B (the 2002 additional types), IEC 60870-6-503 §8 (types and variables), annex G
(the 2002 edition, informative, D-003). The data files are read from the local symlink `docs/spec`: they are not
committed (`.gitignore`), and the generated code contains no standard text, only the clause numbers.
