# T1 — Client API

## Prompt

Run task T1 of `IMPLEMENTATION.md`: the `Client` on `igs-iso9506-mms`: the association, the data sets, the transfer sets, an
event stream of reports, bounded channels with documented back-pressure. Done when there are integration tests against an
in-process server stub.

## Summary

- **Client**: `crates/igs-iec-tase2/src/client.rs`: `TaseClient::associate` (the MMS connection, then the reads of the three
  variables and the check of the link after the Initiate, D-030), the reads and writes of the data values and of the data
  sets, Create and Delete Data Set, Start and Stop Transfer, and `TaseEvents` (the connection states and the transfer reports).
- **Names**: `crates/igs-iec-tase2/src/names.rs`: the conversion of the link's names to the codec's object names.
- **Errors**: `crates/igs-iec-tase2/src/error.rs`.
- **Decisions**: D-045 (the spelling `TASE2_Version`, chosen by the maintainer), D-046 (the MMS mapping, and what is open),
  D-047 (the events and their back-pressure).
- **Tests**: `crates/igs-iec-tase2/tests/client.rs`, 10 tests against an in-process MMS server with the variables of a TASE.2
  server: the association with a matching table and version, and with a mismatching table identifier and TASE.2 version (the
  association is concluded); the reads and writes per item; a data set created, read, written and deleted; a definition
  refused by the server; a transfer set the server does not hold; a transfer report received; the connection state.
- **Dependencies**: `igs-iec-tase2` on the codec (for the MMS types), the sibling link crate (dev-dependency, for the link
  configuration of the tests), and tokio (dev-dependency, for the runtime of the tests).
- **Gate**: `cargo fmt --all --check`, clippy with `-D warnings`, the workspace tests (199 passed), `cargo deny check` and
  `codegen --check`, all green.

## Found on the way

- The name `TASE.2_Version` (503 §8.3.4) is not an MMS identifier without the `char` building block: the codec refuses the dot
  (ISO 9506-2, the production of `Identifier`). The maintainer chose the spelling `TASE2_Version` (D-045). The stub of the tests
  could not hold the printed name either.
- A limit of the MMS stack: the client has no unconfirmed send, so it cannot acknowledge a critical transfer report (D-046).
  This is recorded here and to be recorded in the MMS repository.
- The stub's type of `Bilateral_Table_ID` is a maximum of 32 characters (a negative size in MMS): the value is shorter, as the
  identifier is a visible string of at most 32 (D-004).
