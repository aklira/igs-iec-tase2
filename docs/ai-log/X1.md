# X1 — Documentation and capabilities

## Prompt

Run task X1 of `IMPLEMENTATION.md`: rustdoc on every public item, `examples/`, a README quick start, `CHANGELOG.md`, and
`docs/capabilities.md` with the test of each row. Done when `cargo doc --no-deps` has no warning and every row names an existing
test.

## Summary

- **Rustdoc**: the three library crates have `#![deny(missing_docs)]`. `RUSTDOCFLAGS="-D warnings" cargo doc --no-deps --workspace`
  passes, after a rebuild of every source (the check is not satisfied by the cache).
- **Examples**: `crates/igs-iec-tase2/examples/loopback.rs` (a server and its client in one process: a read, a write, a data set,
  a transfer report) and `examples/probe.rs` (the client against any server). Both are built by the gate.
- **README**: the quick start (test, the loopback example, the demonstration server and its client), the library use, the bench,
  the documents, and the limits (dual use, the scope of 1.0).
- **CHANGELOG**: the 1.0 entries per crate, and the known limits, with their decisions.
- **Capabilities**: `docs/capabilities.md`: the blocks in and out of 1.0; 29 operation and behaviour rows, each naming its tests; the
  known gaps, each with its decision. The test `every_test_named_in_the_capabilities_matrix_exists` checks the names (D-057).
- **Gate**: fmt, codegen, clippy with `-D warnings`, the workspace tests (242 passed), `cargo deny check`, and the rustdoc check, all
  green.
