# M5 — Other types of the chosen blocks

## Prompt

Run task M5 of `IMPLEMENTATION.md`: the types of the chosen blocks that the earlier tasks do not cover. Read IEC
60870-6-802 §6.4 and annex B, as the plan says. Done when each type round-trips.

## Summary

- **Scope**: D-023. The chosen block is Basic Services (D-009). Its data-value types that M1 to M4 do not cover are the
  protection equipment types of 802 §6.2.3. The types of §6.4 (InformationBuffer) and of annex B belong to blocks that
  D-009 leaves out of 1.0; they stay generated and their round trip waits for their block.
- **Model**: `crates/igs-iec-tase2-model/src/protection.rs`: the event state `ProtectionEventState` (OFF 1, ON 2,
  INVALID 0 or 3), the accessors of the flags of `SingleFlags` and `PackedFlags` named by their condition, and those
  of `EventFlags` (the start or trip of each phase). The mapping of `Topical` is inverted and the accessor says so (D-024).
- **Generator**: a bit named `unused` has no constant or accessor, as `reserved` (D-021). The two-bit helpers of
  `indication.rs` are shared with the protection module.
- **Tests**: `tests/protection.rs` (10 tests): the bit positions of the three flag types, every value of each flag
  type round-tripping, the event state and its named values, the state written with the other bits kept, the inverted
  flag, the round trip of the single and packed events, and the refusals of a bit beyond the flags and of a structure
  of the wrong length.
- **Decisions**: D-021 (updated to `unused`), D-023, D-024.
- **Gate**: `cargo fmt --all --check`, clippy with `-D warnings`, the workspace tests, `cargo deny check`, and
  `codegen --check`, all green.

## Found on the way

- The M2 test `indication.rs` used the accessor `is_unused`, which the generator no longer emits: the test now checks
  the bit through the value, since the test's aim is that the bit is kept.
- The mapping of the attribute `Topical` is inverted (a set bit is NOTTOPICAL): the accessor is named `not_topical`.
- The start and the trip of a phase share one bit in the packed event flags: the accessors name the phase, not the
  start or the trip.

## Reading

IEC 60870-6-802 §6.2.3 (the bit tables and the structures), §7.1.3 (the protection event mapping: the attributes, their
bits and their values). IEC 60870-6-702 A.3, Table A.4 (the scope footnote, for the block of the data values). No
standard text is in the code or the documents.
