# C6 — Client API and `igstase2-client`

## Prompt

Run task C6 of `IMPLEMENTATION.md`: the client methods and commands for the three blocks (information messages, select, operate and set tag,
the extended conditions).

## Summary

- **Client** (`crates/igs-iec-tase2/src/client.rs`): `TaseEvent::Information` (the decoded information message), `start_information_transfer`
  and `stop_information_transfer` (the AA-specific `IM_Transfer_Set`), `select_device` (read of `<device>_SBO`), `operate_device` (write of the
  command), `get_tag` and `set_tag` (`<device>_TAG`, the Tag_Value). The reports that are information messages are told apart from the
  transfer reports by their variables.
- **Command line** (`crates/igstase2-client/src/main.rs`): `select`, `operate` (with `--direct`), `get-tag`, `set-tag`, `start-info`,
  `stop-info`; and the block-2 options of `start` (`--integrity-s`, `--buffer-s`, `--tle-s`). `docs/igstase2-client.md` lists them.
- Tests: 7 unit tests in the client (the device variables, the tag codes and the state bit, the code 3 refused, the information report
  decoded, a transfer report not taken for one, a size beyond the buffer refused), 6 unit tests in the command line, 3 of them new
  (the tag names, the tag state text, the command lines of the new commands parse). The full gate is green.
- Decision: D-065 (the variable names, the tag bits, the AA-specific name of `IM_Transfer_Set`, the information report).

## Found on the way

- `IM_Transfer_Set` has the AA-specific scope (503 §8.3.9). The link's object names have only the VMD and domain scopes, so the client writes the
  MMS name itself. The link is not changed for it.
- `TaseEvent` gains a variant. The command line's report loop had an exhaustive match; the new variant is skipped there, as a connection
  event is.

## Not done, and why

- **End-to-end tests of these commands.** The server does not yet serve the device variables or the `IM_Transfer_Set` (C7 does), and the
  test server of the command line has no device. The commands are tested at the unit level here; they are tested end to end in C8, the bench
  and the matrix, which depend on C7.
- **The critical acknowledgement** is still not available to the client (no method, no critical flag on the received report: D-046, D-049).
- **Set-point commands.** `operate` writes an integer, a Boolean or a real. The Control_Setpoint types are written as the value given; no
  check of the type against the device's ControlConfig is made.
