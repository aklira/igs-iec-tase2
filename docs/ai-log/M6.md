## Summary

- **Strategies**: `crates/igs-iec-tase2-model/src/strategy.rs`, behind the feature `strategy` (off by default). Valid
  values of 20 types: integers, identifiers, visible strings, object names, time stamps, the bit strings, the control
  configuration, the select before operate, the tag value, the data-set transfer set, and the protection events.
- **Properties**: `tests/properties.rs`, 25 properties of 10 000 cases each, all passing: random data is read by every
  type without a panic; an accepted value is read back after writing; a valid value round-trips through MMS data and
  its BER encoding; data close to a valid value is read without a panic.
- **Fuzz target**: `fuzz/fuzz_targets/read_types.rs`, a separate workspace (the libfuzzer runtime is not a dependency
  of the library). It reads random bytes as BER data and as each type, and checks the read-back property.
- **Decisions**: D-025 (a real value must be finite), D-026 (the design of the tests, and the known limit of the
  single-precision rounding on write).

## Found on the way

- A single-precision NaN was accepted as a set point, then could not be read back equal to itself. It was found by the
  property tests (the case is kept in `tests/properties.proptest-regressions`). Non-finite reals are now refused (D-025).
