# T3 — Client interop matrix

## Prompt

Run task T3 of `IMPLEMENTATION.md`: the bench scenarios per client operation, and the gaps recorded (rule 10). The reference
peer does not serve TASE.2 (D-010), so the device under test is our own `igstase2-server`.

## Summary

- **Matrix**: `docs/client-matrix.md`: 18 scenario rows, one per operation or behaviour, each naming its test in backticks, and
  one row for the name check; a gap list
  of the behaviour that is not tested (dual use, critical acknowledgement, blocked reports, GetNameList, Data_failure, stop in the
  same association, unsigned writes, several associations and TLE).
- **Scenarios**: `bench/tests/test_t3_client_matrix.py`, 19 tests: 18 scenarios against the device and the client in their
  containers, and one test that checks every test the matrix names exists.
- **Bench**: the compose services `device-tase2` (the device, unchanged) and `client-tase2` (new: `igstase2-client` mounted, in
  `172.31.110.22`). `bench/device/build-tase2.sh` builds both binaries in the bookworm image.
- **Run**: all 19 tests pass against the bench. The log is `bench/transcripts/T3-run.txt`.
- **Demonstration file**: the simulation of `Flow1` now changes every minute (it changed every second). A value written by a
  client stayed visible for less than a second, so a write-then-read test could not be deterministic. The other points keep
  their simulations, which the reports use.

## Found on the way

- The matrix's name check caught one row whose test name differed by one word (`is_listed`/`are_listed`). The check is the
  matrix's own guard: the names are mechanical, so it fails on any drift.
- A data-set write of the bench shows the per-member refusal: only `Flow1` is writable for the client; `Level`, `Temperature`
  and `Breaker` answer `ObjectAccessDenied` in the same response.

## Not done

- The gaps of the matrix, which are recorded and not tested.
- The capture of the TASE.2 frames (tshark decoding for the TASE.2 bench): the matrix checks the client's answers, not the wire.
