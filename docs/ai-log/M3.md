# M3 — Control points and device outage

## Prompt

Run task M3 of `IMPLEMENTATION.md`: the control points (select before operate, the tags, the control configuration) and
the device outage messages of IEC 60870-6-802 §5.3, §6.3, §7.2 and §8.3. Done when each type round-trips.

## Summary

- **Generator**: the integers of the data that carry a `constraint: range least .. greatest` are generated with those
  bounds (`MIN`, `MAX`, and the refusal outside them). Nine items of the 802 data have a range; the others keep the
  bounds of their width (D-019). The generated code is regenerated, and `codegen --check` passes.
- **Tests**: `tests/control.rs` (12 tests): the select state as a boolean, the control commands and the discrete and
  real set points at their limits, the tag flags and their bits (including the bit string of MMS), the tag value, the
  select before operate with its time out, the control configuration within its ranges, the refusal of a control point
  type outside its range, the refusal of a structure of the wrong length, and the round trips of the three outage
  messages (plan, cancellation, actual).
- **Decisions**: D-019.
- **Gate**: `cargo fmt --all --check`, clippy with `-D warnings`, the workspace tests, `cargo deny check`, and
  `codegen --check`, all green.

## Found on the way

- The bit string of the tag flags uses the most significant bit first: the tag high flag is the top bit of the octet.
  The test encodes this directly, with five unused bits.
